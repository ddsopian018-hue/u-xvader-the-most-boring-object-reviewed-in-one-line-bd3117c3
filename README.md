A one-line review of the most boring everyday object I could think of — the doorstop. The line is 184 characters: *"The doorstop: five years holding one door open, zero promotions, zero sick days, never once complained. The hardest-working employee in this house, and HR still won't return its calls."* The object is genuinely boring, the observation (it holds one door open for years, unnoticed and unthanked) is true, and the joke — the hardest-working employee in the house, ignored by HR — lands on the last beat of a single line.

## Run it

Requires Python 3.

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the review line (no trailing newline) to `output/entry.txt`, after gate-checking it: 1–200 characters, valid UTF-8, a single line, not whitespace-only.
